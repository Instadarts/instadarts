# InstaDarts

InstaDarts is a self-hosted darts application with browser-based match screens and camera scoring
devices.

## Install and run

InstaDarts requires Node.js 22 or newer. Download the **Source code (zip)** asset from a GitHub
Release, extract it, and run:

```sh
npm install
npm run build
npm start
```

The server prints the network addresses it listens on. Open one of those addresses rather than
`localhost` so join and scoring-device links also work from other devices. Stop the server with
Ctrl+C.

The production build generates `dist/client/THIRD-PARTY-NOTICES.txt`; it is also available from the
running application through **Settings → Third-party notices**.

## Configuration

The included `instadarts.config.example.jsonc` lists every deployment setting at its default. Copy
it to `instadarts.config.jsonc`, edit the copy, and restart the server. See
[the development documentation](docs/development.md#settings) for details.

## Development

Use `npm run dev` for the API/WebSocket server and Vite client together. Run `npm test` for the unit
suite and `npm run test:e2e` for the browser suite. The internal documentation starts at
[docs/README.md](docs/README.md).

See [CONTRIBUTING.md](CONTRIBUTING.md) before submitting an issue or pull request. Planned
user-facing work is listed in [ROADMAP.md](ROADMAP.md), and notable completed changes are recorded in
[CHANGELOG.md](CHANGELOG.md).
